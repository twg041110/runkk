# 런크크 (runkk)

러닝 플랫폼 모바일 애플리케이션 

## 🛠 Tech Stack
- **Frontend:** React Native (Expo)
- **Backend:** Spring Boot, MariaDB

---

## 🚀 Getting Started

### 1. Backend (`demo`)
```bash
cd demo
# Windows
./gradlew.bat bootRun

# Mac/Linux
./gradlew bootRun

### 2. Frontend (`runkk-app`)
```Bash
cd runkk-app
npm install
npx expo start

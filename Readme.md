# 런크크 (runKK)

러닝 플랫폼 모바일 애플리케이션 및 백엔드 서버

## 🛠 Tech Stack
- **Frontend:** React Native (Expo)
- **Backend:** Spring Boot, MariaDB

---

## 🚀 시작하는 법

프로젝트를 실행하려면 터미널에서 아래 명령어들을 순서대로 입력하세요.


### 1. 백엔드 실행 (demo 폴더)
```cd demo```
#### Windows 사용자
```./gradlew.bat bootRun```
##### Mac/Linux 사용자
```./gradlew bootRun```

### 2. 프론트엔드 실행 (새 터미널을 열고 runkk-app 폴더로 이동)
```cd runkk-app```
```npm install```
```npx expo start```
